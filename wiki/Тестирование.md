# Тестирование

Эталонный уровень проверки: для каждого модуля и функции есть тесты основного сценария, граничных случаев, ошибок и безопасности. Правила изменения тестов: [Разработка и сборка → Тесты и проверки как эталон](Разработка-и-сборка).

## Карта покрытия: приложение (Swift)

Запускается `swift test` на macOS (GitHub Actions: macOS app, release). Облачный модуль дополнительно собирается на Linux (Cloud).

| Модуль | Что проверяется | Файлы тестов |
|---|---|---|
| Модели лида (`Models`) | JSON в формате Python-версии, терпимость к пропущенным и битым полям, email и телефоны, домен, ключи сортировки | `ReferenceCoreTests` |
| Нормализация и даты (`Util`) | домен, телефон, email, название; даты Python, часовые пояса, микросекунды; каталог источников | `ReferenceCoreTests`, `CoreTests` |
| SQLite (`SQLite`) | типы и NULL, привязка параметров (защита от подстановки SQL), транзакции и откат, ошибки, только чтение, закрытая база | `ReferenceCoreTests` |
| Хранилище лидов (`LeadStore`) | сохранение и дубли, избранное, архив, удаление, заметки, просмотр, журналы, состояние источников, память запросов, исключения, импорт CSV, резервные копии, перенос базы, перезапуск | `ReferenceCoreTests`, `CoreTests` |
| Экспорт и CSV (`Export`) | значения всех полей, CSV с BOM и экранированием, защита от формул, JSON, разбор CSV | `ReferenceCoreTests`, `CoreTests` |
| Черновики обращений | каналы, тема письма, подпись, зависимость от фактов | `ReferenceCoreTests`, `CoreTests` |
| Учётные записи (`Accounts`) | правила имени и пароля, регистр, пауза после неудачных входов, пароль не хранится открытым, смена пароля | `ReferenceCoreTests`, `SearchTests` |
| Поиск (`LeadSearch`) | оценка совпадает с Python, разбор источников, настройки, повторные запуски, сбой источника | `SearchTests` |
| Обновления и отчёты о сбоях | версии, выбор релиза, проверка контрольной суммы, разбор отчётов, вычистка личных данных | `UpdateTests`, `CrashReportTests` |
| Экспорт в CRM | адреса и вебхуки, поля Bitrix24, схема и сопоставление Notion, ответы и ошибки, журнал отправленных, обработчик (дубли, остановка при ошибке доступа) | `CRMExportTests` |
| Облако (`LeadCloud`) | вход и регистрация, лимиты писем, обновление сессии, журнал изменений, синхронизация между двумя устройствами через настоящий сервер | `CloudTests`, `StackTests`, стенд `supabase/tests` |

| Интерфейс: состояние (`LeadGenerator`) | разделы и счётчики, фильтры и поиск, выбор лидов и его сброс, вкладки и открытие «Экспорт в…», сопоставление Notion, масштаб, тема, разделы настроек, действия меню | `UIStateTests` |
| Интерфейс: отрисовка | все экраны, настройки, окно экспорта (каждая вкладка), боковая панель, инспектор строятся и раскладываются без сбоя: с общими объектами окружения и без них (класс вылетов из issue #27), при всех масштабах, в светлой и тёмной теме, на пустых данных | `ViewRenderTests` |

Отрисовка проверяется без окна на экране: тесты ловят сбои построения, но не внешний вид. Значок в Dock, системное меню и пиксели проверяются запуском приложения в CI (smoke test) и вручную.

## Карта покрытия: Python-версия

Запускается `python3 -m pytest`, покрытие строк около 91% (`pytest --cov=src/leadgen`).

| Модуль | Файлы тестов |
|---|---|
| Настройки, секреты, режимы | `test_reference_cli.py` |
| Вычистка секретов из логов | `test_reference_cli.py`, `test_http.py` |
| Командная строка (`run`, `state`, `export`, `diagnose`, `notion-init`) | `test_reference_cli.py`, `test_pipeline.py` |
| HTTP-клиент, повторы, лимиты | `test_http.py` |
| Источники (RSS, Telegram, VK, OSM, проверка сайтов) | `test_sources.py`, `test_telegram.py` |

| Хранилище, дубли, шифрование состояния, экспорт | `test_store.py` |
| Notion | `test_notion.py` |
| Интеграции (Hunter, вебхук) | `test_integrations.py` |
| Конвейер и расписание | `test_pipeline.py` |
| Права и настройки workflow | `test_workflows.py` |

## Как проверяется то, что нельзя автоматизировать

- Bitrix24 и Notion проверены только по документации API и тестами на разборе ответов. Живые порталы и базы не проверялись.
- Значок в Dock, меню и окна проверяются вручную на Mac.
