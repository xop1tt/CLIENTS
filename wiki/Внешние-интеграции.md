# Внешние интеграции

Интеграции используются [Python-версией в GitHub Actions](Поиск-в-GitHub-Actions). Приложению для macOS они не нужны.

| Сервис | API | Бесплатный постоянный доступ | AI-функции через API | Статус |
|---|---|---|---|---|
| Notion | Да | Да, API доступен на бесплатном тарифе; лимит в среднем 3 запроса/с | Нет | ✅ Основное хранилище |
| Telegram Bot API | Да | Да | Нет | ✅ Уведомления |
| Hunter.io | Да (Domain Search) | Да, бесплатный тариф 50 кредитов/мес (hunter.io/pricing) | Нет, в API только данные о контактах | ✅ Адаптер готов, выключен |
| Make | Да, входящие webhook | Бесплатный тариф есть; размер лимита операций не проверялся | Есть AI-модули, но бесплатность в API не подтверждена | ✅ Через универсальный webhook, выключен |
| n8n Community Edition | Да, webhook | ПО бесплатное, но нужен свой сервер; можно запустить на своём компьютере | Да, если подключить локальную модель (например, Ollama) | ✅ Через универсальный webhook, выключен |
| Snov.io | Да | 50 кредитов/мес, но **API на бесплатном тарифе только по запросу через демо** (snov.io/api) | Нет | ❌ Не подключён |
| Apollo.io | Да | Бесплатный тариф есть; доступ к API на нём подтвердить не удалось | AI-задачи Assistant тратят кредиты | ❌ Не подключён |

Ни один сервис не даёт бесплатного постоянного AI-анализа через API, поэтому основная фильтрация работает на правилах.
Самый реальный бесплатный вариант AI: n8n + локальная модель на своём компьютере, подключённые через webhook.
Ограничение: компьютер должен быть включён.

## Telegram-уведомления

Бот присылает новые лиды, дайджест, ошибки источников одним сообщением, сообщение о восстановлении и сводку раз
в сутки. Фразы уведомлений с юмором. В режиме `dry-run` ничего не отправляется.

## Как устроены адаптеры

- У каждого адаптера своя секция в `integrations`: `enabled`, `route` (какие лиды отправлять), `fields` (какие поля
  передавать), `max_per_run`, `monthly_quota`.
- Повторно одна заявка в тот же сервис не отправляется.
- Результат хранится отдельно (`external_results`) и не меняет исходные данные.
- Итоговая оценка = 75% своя + 25% средняя внешняя (`scoring.external_weight`).
- После 3 ошибок подряд адаптер пропускается до следующего запуска, остальная система продолжает работу.
- В режиме dry-run во внешние сервисы ничего не отправляется.
- Hunter по умолчанию тратит не больше 25 кредитов в месяц.

### Формат webhook

POST JSON с полями из `fields`, заголовок `X-Leadgen-Signature` с HMAC-SHA256 тела (ключ `WEBHOOK_SECRET`).
Ответ необязателен; если он есть, ожидается формат:

```json
{"score": 0, "label": "строка", "comment": "строка", "details": {}}
```

где `score` от 0 до 100.

## Подтверждённые бесплатные лимиты

Указаны только лимиты, подтверждённые официальными страницами на 05.11.2026.

| Компонент | Условие |
|---|---|
| GitHub Actions | Стандартные раннеры в публичных репозиториях бесплатны. Кэш до 10 ГБ на репозиторий, записи без обращений 7 дней удаляются. Расписание отключается после 60 дней без активности в репозитории |
| Hunter.io | 50 кредитов в месяц (поиск email = 1, проверка = 0,5). Адаптер по умолчанию тратит не больше 25 |
| Snov.io | 50 кредитов в месяц, API на бесплатном тарифе только по запросу |
| 2ГИС | Демо-ключ: один раз, на 1 месяц, поэтому не используется |
| Яндекс Карты | Бесплатно только без сохранения данных, поэтому не используется |
| Overpass API | Публичный сервер, правила честного использования. 1 запрос на пару «регион × категория» не чаще раза в неделю |
| Supabase (облако приложения) | Free: 2 активных проекта на организацию, база до 500 МБ, пауза после 7 дней без запросов. См. [Учётные записи и облако](Учётные-записи-и-облако) |
