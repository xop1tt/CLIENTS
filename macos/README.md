# Lead Generator для macOS

Нативное приложение на SwiftUI (macOS 14 Sonoma и новее) для работы с лидами, которые находит поиск в GitHub Actions.
Без регистрации, аккаунтов и платных сервисов. Все данные хранятся на вашем Mac.

## Как это устроено

```
GitHub Actions (раз в час)                         Ваш Mac
  поиск → scoring → дедупликация                     Lead Generator.app
  state/leadgen.db.enc  ── артефакт leadgen-state ──▶  скачать (токен GitHub)
  (Fernet, ключ STATE_ENCRYPTION_KEY)                  расшифровать (тот же ключ)
                                                       влить в ~/Library/Application Support/Lead Generator/leads.db
```

- Поиск остаётся в GitHub Actions, как и раньше. Notion и Telegram продолжают работать, если они включены.
- После каждого запуска workflow публикует зашифрованную базу как артефакт (`leadgen-state`, хранится 3 дня).
  Без ключа шифрования файл не прочитать, поэтому публичный репозиторий лиды не раскрывает.
- Приложение скачивает артефакт, расшифровывает его локально и добавляет новые лиды. Избранное, архив,
  заметки, удаления и исключения синхронизация не перезаписывает.

## Что умеет первая версия

- Три панели: навигация слева, таблица лидов в центре, контекстная панель справа. Боковые панели
  сворачиваются и меняют ширину, правая скрывается кнопкой или ⌥⌘I.
- Разделы: Главная, Все лиды, Новые, Избранное, Архив, Исключённые, Источники, История запусков.
- Таблица: сортировка по любому столбцу, фильтры (тип, источник, регион, минимальная оценка), поиск
  по названию, описанию, контактам и заметкам, массовые действия, контекстное меню.
- Панель лида: оценка и её причины, факты отдельно от предположений, контакты, результаты внешних
  анализаторов, заметка, история изменений, черновик первого обращения (шаблон, отправка только вручную).
- Исключения: домены (включая поддомены), телефоны, email, названия, импорт своей базы клиентов из CSV.
- Экспорт выбранных или отфильтрованных лидов в CSV (с BOM для Excel) и JSON с выбором полей.
- Источники: состояние из Actions, ошибки, честные условия доступа; недоступные бесплатно источники показаны отдельно.
- История запусков из GitHub Actions: статус, длительность, ссылка на логи, повтор упавшего запуска,
  ручной запуск поиска (⇧⌘R).
- Настройки:
  - **Внешний вид:** тема (как в системе / светлая / тёмная), акцентный цвет, шрифт интерфейса из
    установленных на Mac, моноширинный шрифт, масштаб интерфейса 80–150% (⌘+ / ⌘− / ⌘0), плотность строк.
  - **Синхронизация:** репозиторий, токен GitHub и ключ шифрования (в Связке ключей macOS), автопроверка.
  - **Данные:** расположение базы и перенос, ежедневные резервные копии, восстановление, перенос на другой Mac.
  - **Исключения** и **Обращения** (подпись в черновиках).

Ещё не сделано (следующие этапы): редактор направлений поиска и настроек источников (сейчас они в
`config.yaml`), аналитика, конструктор сценариев, Ollama, экспорт XLSX/PDF/XML.

## Установка

### Вариант 1. Готовая сборка из GitHub Actions

1. Откройте вкладку **Actions → macOS app**, последний успешный запуск, раздел **Artifacts** и скачайте
   `Lead-Generator-macOS`.
2. Распакуйте и перенесите «Lead Generator» в «Программы».
3. Первый запуск: правый клик по приложению → **Открыть** → **Открыть**. Сборка подписана локально
   (ad-hoc), без платного Apple Developer ID, поэтому macOS спрашивает подтверждение один раз.

### Вариант 2. Сборка из исходников

Нужны Xcode 15+ или Command Line Tools (`xcode-select --install`).

```bash
cd macos
swift test                     # тесты ядра
./scripts/build-app.sh         # соберёт build/Lead Generator.app
open "build/Lead Generator.app"
```

Для разработки: `open Package.swift` откроет проект в Xcode, схема `LeadGenerator`.

## Настройка синхронизации

1. Поиск в репозитории уже настроен по основному README, включая секрет `STATE_ENCRYPTION_KEY`.
2. Создайте fine-grained токен: github.com → Settings → Developer settings → Personal access tokens →
   Fine-grained tokens → Generate. Repository access: только этот репозиторий. Permissions → Actions:
   **Read and write** (чтение артефактов и запуск поиска). Срок действия выберите сами.
3. В приложении: **Lead Generator → Настройки… (⌘,) → Синхронизация**. Проверьте владельца и репозиторий,
   вставьте токен и то же значение `STATE_ENCRYPTION_KEY`, нажмите «Сохранить», затем «Синхронизировать сейчас».

Первый артефакт появится после ближайшего запуска поиска с этими изменениями. Можно запустить поиск сразу
из приложения кнопкой ▶︎.
